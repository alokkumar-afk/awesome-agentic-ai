# Security Policy

## Reporting a Vulnerability

Please **do not open a public issue or pull request for a security vulnerability**.

Use GitHub's private vulnerability reporting feature:

https://github.com/Titan-Codes-Official/awesome-agentic-ai/security/advisories/new

This allows a report to be shared privately with repository maintainers.

## What Counts as a Security Concern?

This repository is primarily a curated Markdown resource list, but security concerns can still include:

- A listed resource that has been compromised and now serves malicious content.
- Phishing, credential-stealing, malware, or deceptive links.
- A pull request attempting to add malicious HTML, scripts, or executable files.
- Unexpected changes to `.github/` configuration or repository policy files.
- GitHub Actions or workflow changes that could execute untrusted code.
- Attempts to expose secrets, credentials, private data, or personal information.
- A repository configuration problem that could bypass intended review controls.

Broken links, renamed projects, or normal content corrections are not security vulnerabilities. Use the regular issue templates for those cases.

## Disclosure

Please provide enough information for maintainers to understand and reproduce the issue where applicable. Avoid publicly disclosing details until the maintainers have had an opportunity to review the report.

## External Resources

Awesome Agentic AI contains links to third-party websites and repositories. Inclusion does not imply that Titan Codes controls those resources. If a third-party resource becomes unsafe or compromised, please report it so the link can be reviewed and removed promptly.
